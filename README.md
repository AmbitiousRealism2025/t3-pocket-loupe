# T3 Pocket Loupe

T3 Loupe on your iPhone: a read-only, tailnet-only home-screen web app for [T3 Code](https://github.com/pingdotgg/t3code) agents.

**Status:** under construction (0.1.0). The full README arrives with milestone M4.

- It shows what every T3 Code thread is doing, across every machine [T3 Loupe](https://github.com/AmbitiousRealism2025/t3-loupe) is paired with.
- It is read-only. Approvals and answers still happen in T3.
- It is reached only over your own Tailscale network, through `tailscale serve`. No cloud, no public URL, no login.
- It is built to the [NixWeb Standard](https://github.com/nixfred/nixweb.app), Level 2.

See [docs/PROPOSAL.md](docs/PROPOSAL.md) for the design and [PLAN.md](PLAN.md) for the build plan.
